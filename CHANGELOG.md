# Changelog / 更新日志

---

## 1.0.0

**English**

- Initial release.
- Fluro-based routing with annotations and code generation.
- Path params, query params, and `RouteSettings.arguments` support.
- Animated transitions and custom navigation.

**中文**

- 初始版本发布。
- 基于 Fluro 的注解 + 代码生成路由。
- 支持路径参数、查询参数、RouteSettings.arguments 传参。
- 支持动画转场与自定义导航。
